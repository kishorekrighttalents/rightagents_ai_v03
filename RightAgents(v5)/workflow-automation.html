Frequently asked

How is this different from UiPath or Zapier?+
Traditional RPA like UiPath and rule platforms like Zapier rely on static UI selectors and brittle API step chains. RightAgents uses supervisor-led agent networks that reason about dynamic changes, infer context on anomalies, and autonomously self-heal workflows without hard failure interruptions.
What happens with an edge case the agent hasn't seen?+
When an unknown edge case encounters low confidence scores, the system gracefully hands off the ticket into the Governed Human-in-the-Loop Cockpit. The human supervisor is shown the exact chain of thought, makes the decision in one click, and the agent permanently learns the pattern.
Can agents execute unauthorized financial writes?+
No. All writes and critical mutations adhere strictly to deterministic enterprise governance policies and RBAC bounds configured by your security team. High-stakes actions trigger mandatory dual-custody or authorized sign-off routines.
